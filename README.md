# ROZCLUB × OpenKore (XKore 1)

บอท OpenKore สำหรับเซิร์ฟเวอร์ ROZCLUB แบบ XKore 1 (บอทเล่นผ่านหน้าต่างเกมจริง) หลายตัวพร้อมกัน
พร้อมโปรแกรมควบคุมแบบหน้าต่าง **ROZ Bot Control**

## ใช้งาน

| ทำอะไร | ไฟล์ |
|---|---|
| เปิดโปรแกรมควบคุม (GUI) | `Start-GUI.cmd` |
| เปิด GUI แบบ Administrator | `Start-GUI-Admin.cmd` (จำเป็นสำหรับล็อกอินอัตโนมัติ) |
| เปิดบอททุกตัว | `Start-ROZ-All.cmd` |
| เปิดทีละตัว | `Start-ROZCLUB-XKore1.cmd` (potato7), `Start-ROZCLUB-XKore1-kiminoto.cmd` |
| คำสั่งจัดการ | `roz list` · `roz status` · `roz check` · `roz start <ชื่อ\|all>` · `roz game <ชื่อ>` · `roz gamepid <ชื่อ>` · `roz new …` · `roz remove …` · `roz build` |
| เพิ่ม / ลบบอท | ปุ่ม ➕ / ➖ ที่แถบซ้ายของ GUI (เรียก `scripts\roz.ps1 new` / `remove` ให้เอง) |

การเปิดเกมต้องใช้สิทธิ์ Administrator (มีหน้าต่าง UAC ถาม) เพราะ `Ragnarok.exe` ต้องการสิทธิ์นี้

เพิ่มบอทจาก GUI: ตั้งชื่อ (a-z, 0-9, `_` และ `-`) แล้วเลือก **คัดลอกการตั้งค่าจากบอทที่มีอยู่** หรือ
**Support** (เดินตาม ฮีล และบัฟบอทที่เลือก) · พอร์ตเลือกอัตโนมัติหรือกำหนดเองได้ · บอทสายตีต้องคัดลอก
จากบอทที่มีอยู่ เพราะ `roz.ps1` มีแม่แบบแค่สาย Support · รายชื่อบอทอัปเดตทันทีโดยไม่ต้องปิดโปรแกรม
ส่วนการลบเลือกได้ว่าจะเก็บหรือลบโฟลเดอร์โปรไฟล์ และลบไม่ได้ถ้าบอทยังรันอยู่

### ขาย / ฝากของ

แท็บ **ตั้งค่าบอท → ขาย / ฝาก**: เลือก Kafra และ NPC ขายจากรายชื่อ NPC ของเมืองเซฟ (ฐานข้อมูล
rozclub.com, เก็บไว้ที่ `gui\cache\npcs.js`) แล้วตั้งแต่ละไอเทมเป็น ไม่ยุ่ง / เก็บในตัว / ฝาก Kafra / ขาย NPC
(ฝาก/ขายกำหนด "เหลือไว้ในตัว" ได้) · GUI เขียนช่วงของตัวเองไว้ท้าย `items_control.txt` (ชนะค่าเดิม
และค่าจาก market scanner ซึ่งเก็บช่วงนี้ไว้ตอนเขียนทับ) · OpenKore หาไอเทมจากชื่อก่อน ID
ไอเทมที่ OpenKore ตั้งชื่อซ้ำกัน (เช่น Concentration Potion 645 กับ 22542) จึงใช้ค่าเดียวกันเสมอ

### ล็อกอินอัตโนมัติ (ตอนเริ่มบอท และเมื่อหลุด)

ในโหมด XKore 1 เกมเป็นคนล็อกอินและเลือกตัวละคร OpenKore จึง reconnect เองไม่ได้
GUI จะพิมพ์บัญชีและเลือกตัวละครให้ผ่านหน้าต่างเกม (Win32 SendInput):

1. เปิด GUI ด้วย `Start-GUI-Admin.cmd` (UAC 1 ครั้ง) — Windows บล็อกการส่งคีย์บอร์ดไปยังเกม
   ที่ elevated ถ้าโปรแกรมไม่ได้เป็น Administrator
2. ไปที่แท็บ **ตั้งค่าบอท → ล็อกอินอัตโนมัติ** ใส่ Username / Password / ช่องตัวละคร
   / ช่องเซิร์ฟเวอร์ แล้วกดบันทึก (รหัสผ่านเข้ารหัส Windows DPAPI เก็บที่
   `%APPDATA%\ROZBotControl\accounts.json` ไม่อยู่ใน git และไม่เขียนลง `config.txt`)
   · หลังล็อกอินเกมจะมี **หน้าเลือกบริการ** (วาดในเกม) ระบบกด Enter ทันทีที่ OpenKore เห็นหน้านี้
   (ถ้ารอนานเกม ~14 วินาที เกมจะขึ้น "เชื่อมต่อเซิร์ฟเวอร์ล้มเหลว") แล้วรอหน้าเลือกตัวละคร
   · ทุกขั้นรอสถานะของ OpenKore: 1 login · 2 เลือกบริการ · 3 เลือกตัวละคร · 4 โหลดแผนที่ · 5 ในเกม
   · หน้าเลือกตัวละคร: คลิกการ์ดช่องที่ตั้งไว้ อ่านจากภาพว่าการ์ดไหนถูกเลือก (แก้ด้วยลูกศรถ้าไม่ตรง)
   แล้วค่อยกด Enter — ถ้าช่องว่างหรือยืนยันการ์ดไม่ได้จะหยุดโดยไม่กด (ต้องตั้งเกม 1024×768, ช่อง 1–15)
   · ROZCLUB เตะการเข้า map ครั้งแรกกลับหน้า login หนึ่งครั้ง (มีกล่อง "เกิดข้อผิดพลาดที่ไม่ทราบสาเหตุ")
   ระบบจะกด Enter ปิดกล่องแล้วล็อกอินใหม่ให้เอง (สูงสุด 2 รอบ) และนับว่าสำเร็จเมื่ออยู่ในเกมได้ 20 วินาที
3. กด **▶ เริ่มบอท** ตามปกติ — ถ้าเปิดล็อกอินอัตโนมัติไว้ ระบบจะรอเกมโหลด
   (ช่อง "รอเกมโหลดหลังกดเริ่มบอท" ค่าเริ่มต้น 20 วินาที) แล้วล็อกอินให้เอง
   ถ้าคุณล็อกอินเองก่อน ระบบจะไม่ทำซ้ำ
4. กด **ทดสอบล็อกอินตอนนี้** ขณะบอทอยู่หน้า login (logout ตัวละครในเกมก่อนได้) เพื่อปรับดีเลย์
   และดูภาพหน้าจอใน `%APPDATA%\ROZBotControl\relogin-debug`

ข้อจำกัด: ต้องไม่ล็อกจอ/ไม่สลีประหว่างทำงาน · ต้องไม่มี PIN/OTP · ถ้าปิดหน้าต่างเกมไปเลย
ระบบนี้ยังเปิดใหม่ไม่ได้ (ต้องเปิดเกม/ล็อกอินด้วยมือ) · หยุดลองหลัง 3 ครั้งเพื่อกันล็อกบัญชี
· **หลุดระหว่างฟาร์ม:** ถ้าบอทเคยเข้าเกมแล้ว OpenKore ยังเปิดอยู่แต่กลับไปหน้า login นานเกิน
"ถือว่าหลุดเมื่อออฟไลน์" (ค่าเริ่มต้น 20 วินาที) ระบบจะเริ่มเอง — กด Enter ปิดกล่องในเกม ("การเชื่อมต่อเซิร์ฟเวอร์ถูกตัดขาด" ฯลฯ,
ตรวจจากภาพที่ 1024×768) ก่อนพิมพ์รหัส ถ้ากล่องไม่ปิดจะไม่พิมพ์ · กด ⏹ ปิดบอท / ✖ บังคับปิด
ระบบจะไม่ล็อกอินให้ · `roz game <ชื่อ>` เปิดเฉพาะหน้าต่างเกมของบอทที่
OpenKore รออยู่ และ `roz gamepid <ชื่อ>` ดู pid เกม

## โครงสร้าง

```
instances.json        รายชื่อบอท (ชื่อ, port, โฟลเดอร์ profile, role)
roz.cmd, Start-*.cmd  ตัวเปิด (เรียก scripts\roz.ps1)
bots\<ชื่อ>\          profile ของบอทแต่ละตัว: control\ (config) · tables\ · logs\
gui\                  ROZ Bot Control (Python/Tkinter) — rozgui\ คือโค้ด, cache\ คือข้อมูลเกมที่โหลดมา
plugins\gui_ipc\      ปลั๊กอิน OpenKore ที่ส่งสถานะ/รับคำสั่งจาก GUI
plugins\rozclub_market\ ปลั๊กอินสแกนราคาตลาด (คำสั่ง market …)
scripts\              roz.ps1 (ตัวจัดการหลายบอท) · templates\ (แม่แบบ config) · bin\ (NetRedirect DLL ที่ build)
runtime\              Perl 32-bit, XSTools.dll, launcher — ไฟล์ไบนารี ไม่อยู่ใน git
src\native\           source ของโปรแกรม native ใน runtime\
docs\                 บันทึกการตั้งค่าเดิมและผลการวิเคราะห์ (FINDINGS)
tools\                เครื่องมือแยก (packetExtractor มี git ของตัวเอง)
_archive\             ไฟล์ .bak เก่า, packet capture, build เก่า — เก็บไว้ในเครื่อง ไม่อยู่ใน git
```
